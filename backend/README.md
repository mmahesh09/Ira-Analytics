# Rankwise API

FastAPI backend for [Rankwise](https://rankwise-xi.vercel.app): SEO, answer-engine (AEO) and AI-visibility (GEO)
audits, monitoring, issue history and AI rewrites. Built from `Dockerfile` in this folder.

Configuration is through environment variables (Space **Settings → Variables and secrets**). See `DEPLOY.md`
in the main repository for the full list and setup order.
