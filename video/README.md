# Rankwise launch video

Two compositions, both 30 s · 1920×1080 · 30 fps, built with [Remotion](https://remotion.dev). Brand tokens match the
site (`src/theme.ts`); the logo is the site's own mark from `frontend/src/components/site-header.tsx`.

## Cinematic film (`RankwiseFilm`)

```bash
npm install
npm run sfx           # synthesize the sound effects → public/sfx/*.wav
npm run fx            # HyperFrames: grain loop + atmosphere plate → public/fx/*.mp4
npm run render:film   # → out/rankwise-film.mp4
```

On a machine with 8 GB of RAM or less, render one plate at a time with `--low-memory-mode -w 1` and the film with
`--concurrency=1`.

| Time | Shot | Notes |
|---|---|---|
| 0–4.1 s | Opening | Darkness, beam sweep, particles, masked type |
| 4.1–8 s | Build | "Who's deciding who gets recommended?", SEO / AEO / GEO, blackout before the drop |
| 8–11.9 s | Reveal | Logo with light sweep and push-in on the drop |
| 11.9–17.7 s | Showcase | Macro on the score ring, pull-back to the full dashboard in 2.5D |
| 17.7–23.5 s | Features | Four whip-panned feature shots with real UI close-ups |
| 23.5–30 s | Finale | Logo, tagline, "Audit your site free.", URL |

- The scenes are in `src/film/`.
- The dashboard (`Dashboard.tsx`) is a data port of the site's `hero-preview.tsx`: northwind-coffee.com, overall 67, SEO 88 / AEO 54 / GEO 41 / Speed 76. Change it there if the site changes.
- The HyperFrames source for the light plates is in `fx/`. Remotion screens the plates over the scenes.
- The sound design is generated by `scripts/make-sfx.mjs`, which is deterministic, so re-running it gives the same files.
- Melodia enters at its drop (0:54.2) on frame 240.

## Original promo (`RankwiseLaunch`)

```bash
npm install
npm run studio        # live preview in the browser
npm run render        # → out/rankwise-launch.mp4 (silent)
npm run render:audio  # same, with public/voiceover.mp3 + public/music.mp3
```

### Scenes

| Time | Scene | File |
|---|---|---|
| 0–4.1 s | Hook: "Google isn't the only one reading your site anymore." | `scenes/Hook.tsx` |
| 4.1–8 s | Problem: SEO checked, AEO/GEO unchecked | `scenes/Problem.tsx` |
| 8–11.9 s | Logo reveal, on the music drop | `scenes/Reveal.tsx` |
| 11.9–17.7 s | Audit console demo → score rings | `scenes/Demo.tsx` |
| 17.7–23.5 s | Four feature cards | `scenes/Features.tsx` |
| 23.5–30 s | CTA: rankwise-xi.vercel.app | `scenes/Cta.tsx` |

Scene lengths live in `SCENES` in `src/RankwiseLaunch.tsx`. Every cut sits on a bar line of the music
(124 BPM, 1.935 s per bar, counted from the drop at frame 240). Demo scores (92/78/64) are illustrative;
edit `SCORES` in `Demo.tsx`.

## Music

**Syn Cole – Melodia [NCS Release]**, played from 0:46.2 in the track, so its main drop (0:54.19) lands on the
logo reveal at 8.0 s. The backdrop glow flares on each downbeat after the drop, and the CTA button pulses on the beat.

The MP3 is not committed (`public/*.mp3` is gitignored). To render on another machine, copy the track to
`public/music.mp3` and run `npm run render:audio`.

### Voiceover (optional)

Add `public/voiceover.mp3`, set `"voiceover": true` in `audio-props.json`, and render again. The music then drops
from 80% to 15% volume.

Voiceover script (~70 words; aim to finish by 29 s):

> **[0 s]** Google isn't the only one reading your website anymore.
> **[4 s]** AI assistants and answer engines are deciding who gets recommended.
> **[8 s]** Meet Rankwise.

> **[18 s]** plus Core Web Vitals, live AI-mention tests, and a ranked list of exactly what to fix.
